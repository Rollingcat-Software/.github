# Rollingcat-Software

Builders of **FIVUCSAS** — a cloud-based face & identity verification platform:
biometric authentication, liveness / anti-spoofing, and multi-tenant OAuth 2.0 / OIDC.

### Core repositories
| Repository | What it is |
|------------|------------|
| [FIVUCSAS](https://github.com/Rollingcat-Software/FIVUCSAS) | Umbrella / orchestration (docker-compose, submodules) |
| [identity-core-api](https://github.com/Rollingcat-Software/identity-core-api) | Spring Boot authentication & identity backend |
| [biometric-processor](https://github.com/Rollingcat-Software/biometric-processor) | Python face / voice / liveness service |
| [spoof-detector](https://github.com/Rollingcat-Software/spoof-detector) | Anti-spoofing / PAD engine + research |
| [web-app](https://github.com/Rollingcat-Software/web-app) | React / TypeScript admin + hosted login |
| [client-apps](https://github.com/Rollingcat-Software/client-apps) | Kotlin Multiplatform client apps |
| [docs](https://github.com/Rollingcat-Software/docs) | Product & architecture documentation |
| [practice-and-test](https://github.com/Rollingcat-Software/practice-and-test) | R&D / experiments (not production) |
